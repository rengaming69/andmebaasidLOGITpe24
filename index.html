Andmebaasid RENO Konspektid

Andmebaasidega seotud SQL kood ja konspektid

  • SQL Structured Query Language — struktureeritud päringukeel
  • DDL Data Definition Language — andmete kirjeldamise keel (nt. CREATE, ALTER)
  • DML Data Manipulation Language — andmetega manipuleerimise keel (nt. INSERT, UPDATE, DELETE)

Sisukord

Select laused | ForeignKeys | Alter_Table | Triggerid | Kodutöö - Keys

Tunnis kasutatavad andmebaasihaldussüsteemid

  1. SQL Server Management Studio (SQL Serveri haldamiseks)
  2. XAMPP - phpMyAdmin (MariaDB andmebaas) — vabavara

Põhimõisted

Andmebaas

Struktureeritud andmete kogum.

Tabel

Olem (entity).

Veerg

Väli (field).

Rida

Kirje (record).

Primaarne võti (PK - Primary Key)

Veerg (tavaliselt nimega id) unikaalse identifikaatoriga, mis eristab iga kirjet.

Välisvõti / võõrvõti (FK - Foreign Key)

Veerg, mis loob seose teise tabeli primaarvõtmega.

Andmetüübid

INT SMALLINT DECIMAL (6,2) FLOAT CHAR (6) VARCHAR(50) TEXT DATE TIME DATETIME BOOLEAN

Piirangud

primary key foreign key unique not null check

Tabelivahelised seosed

• Üks - ühele (nt. mees — naine)

• Üks - mitmele (nt. õpilane käib erinevates õppeainetes)

• Mitu - mitmele (nt. suhted õpilaste vahel)
